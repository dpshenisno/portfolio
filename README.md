# Portfolio · Данил Пшениснов

Первая страница портфолио: кейс СберУниверситета. Статический сайт без сборки и сторонних JS-зависимостей.

## Файлы

- `dist/index.html` — содержание кейса.
- `dist/style.css` — адаптивная сетка, светлая/тёмная тема.
- `dist/app.js` — переключатель темы и инверсионный курсор.
- `dist/assets` — локальные изображения из авторского кейса и шрифт Inter.

Сервер должен отдавать `dist` как корень. `/sber/` содержит ту же страницу. Главная ссылка ведёт на исходное портфолио, пока новая главная не создана.

Контент и изображения: https://denilok.framer.website/sber
Визуальный ориентир: https://www.offmenu.design/work/tenacity
Шрифт Inter распространяется по SIL Open Font License; см. `dist/assets/OFL.txt`.

Качественные результаты из исходного кейса не превращены в неподтверждённые числовые метрики.
