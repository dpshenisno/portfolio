# Портфолио · Данил Пшениснов

Статический сайт: главная страница и подробный кейс СберУниверситета.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000/`. Кейс Сбера находится по `/sber/`.

## Состав

- `dist/index.html` — главная с проектами и компаниями.
- `dist/sber/index.html` — кейс СберУниверситета.
- `dist/style.css` — адаптивная вёрстка, темы и круги результатов.
- `dist/app.js` — меню, тема, курсор и появление текста.
- `dist/smooth-scroll.js` — плавная прокрутка колесом с поддержкой reduced motion.
- `dist/hero-optics.js` — локальное искажение и направленное размытие верхней части фотографии; без WebGL отображается оригинал.
- `dist/assets/` — изображения, логотипы и Inter с лицензией OFL.

## Публикация на GitHub Pages

Ветка `gh-pages` содержит готовый сайт в корне. В Settings → Pages выберите Deploy from a branch → `gh-pages` → `/(root)` → Save.

После изменений содержимое `dist/` нужно синхронизировать в корень ветки `gh-pages`. Основной код хранится в `main`; сохранённые версии — в ветках `snapshot/`.

Контент и исходные изображения: https://denilok.framer.website/
